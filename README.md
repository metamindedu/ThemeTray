# ThemeTray

**Windows 11의 라이트/다크 모드를 가볍게 전환하는 무료 트레이 프로그램**

Windows 모드와 앱 모드를 각각 제어하고, 한 번 클릭·지정 시간·일출/일몰에 맞춰 전환합니다.

> **공개 테스트 버전: 0.1.0-beta.1**
> 현재 코드 서명이 없는 프로그램입니다. Windows SmartScreen/조직 보안 정책에 의해 경고 또는 실행 제한이 나타날 수 있습니다. 보안 기능을 끄지 마세요. 이 저장소의 공식 릴리스 및 SHA-256을 확인하고, 신뢰할 수 없거나 조직에서 제한한 경우 실행하지 마세요.

## 지원 환경

- **Windows 11 x64**, 일반 사용자 권한
- .NET Framework 4.8 이상 필요(Windows 11에 기본 포함되는 계열)
- 한국어 UI. Python·브라우저 엔진·추가 서버 불필요
- ARM64, Windows 10, 회사 보안 정책으로 테마/위치/시작 앱이 제한된 환경은 이번 버전의 지원 검증 대상이 아닙니다.

## 시작하기

### 설치형 — 권장

1. Setup 파일을 실행하고 안내를 따릅니다. 관리자 권한을 요구하지 않습니다.
2. `%LOCALAPPDATA%\Programs\ThemeTray`에 설치됩니다.
3. 시작 메뉴에서 **ThemeTray**를 실행합니다.
4. 최초 실행은 Windows/앱 모두 수동 모드이며, 로그인 시 자동 실행도 기본으로 꺼져 있습니다.

설치 프로그램은 실행 중인 ThemeTray가 있으면 먼저 종료하도록 안내합니다. 앱을 강제로 종료하지 않습니다. 포터블 버전에서 설치형으로 옮겼다면 새 앱 설정에서 로그인 시 실행 등록 경로를 다시 확인하세요.

### 포터블

1. ZIP을 고정된 폴더에 **모두 압축 해제**합니다.
2. `ThemeTray.exe`를 실행합니다. `ThemeTray.exe.config`도 같은 폴더에 둡니다.
3. 자동 실행을 등록한 뒤 폴더를 옮기면 새 위치에서 다시 등록해야 합니다.

## 주요 기능

- 트레이 아이콘 **왼쪽 한 번 클릭**으로 선택한 대상 전환
- Windows 모드와 앱 모드 **독립 제어**
- 대상별 **수동 / 지정 시간 / 일출·일몰** 일정
- Windows가 허용하고 좌표를 제공하는 경우 **자동 위치 사용**, 실패 시 수동 좌표로 대체
- 12pt 본문·입력 컨트롤, 창 크기에 맞는 줄바꿈·스크롤
- 로그인 시 실행 옵션, 절전 복귀 시 현재 일정 재평가

### 트레이 사용법

- **왼쪽 클릭:** 선택한 대상 전환. 두 대상을 선택했다면 현재 **앱 모드의 반대쪽**으로 둘 다 맞춥니다.
- **오른쪽 클릭:** 모두 라이트/다크, Windows만/앱만 전환, 설정, 종료.
- 작업표시줄에 없다면 **^ 숨겨진 아이콘**에서 찾으세요. 아이콘을 밖으로 꺼내 둘 수 있습니다.
- 다시 실행하면 중복 상주하지 않고 기존 설정 창이 열립니다.
- 설정 창 X/닫기는 트레이 앱을 종료하지 않습니다. 종료하려면 트레이 메뉴의 **종료**를 선택하세요.

### 자동 일정

- 지정 시간은 24시간제입니다. 라이트/다크 시작 시각을 다르게 정하세요.
- 일출부터 라이트, 일몰부터 다크이며 모든 시각은 **PC의 시간대** 기준입니다.
- 수동 변경은 **그 조작 당시 정한 다음 자동 경계**까지 유지됩니다. 위치가 바뀌어도 해당 유지 종료 시각은 보존합니다.
- **저장하고 적용**, 앱 재시작, **자동 일정 지금 다시 적용**은 현재 자동 일정을 적용합니다.
- 일출/일몰은 지형·기상을 반영하지 않는 근사 계산이며 수 분 오차가 있을 수 있습니다.
- Windows 위치 실패 시 쓸 **대체 좌표**도 실제 사용 위치에 맞춰 주세요. 초기 수동 좌표는 서울 예시입니다.

## 위치와 개인정보

- 자동 위치는 선택 사항입니다. Windows 위치 권한을 켜거나 강제로 요청하지 않습니다.
- 자동 일정 사용 시 시작·약 6시간마다 단발 조회하고 완료 후 위치 제공자를 종료합니다. **지금 위치 조회** 버튼으로도 갱신할 수 있습니다.
- 권한 거부·서비스 비활성·오래된 좌표·조회 실패 시 수동 대체 좌표를 사용합니다.
- 자동 좌표는 소수 둘째 자리로 줄여 메모리에서만 사용하고, 설정 파일·오류 로그에 기록하지 않습니다.
- 수동 입력 좌표와 일정은 PC의 설정 파일에 저장됩니다.
- ThemeTray는 IP 위치 API, 광고, 분석 서버, 텔레메트리를 사용하지 않습니다. Windows 위치 서비스 자체의 네트워크 처리는 Microsoft 설정·정책에 따릅니다.
- OS에서 위치 권한을 끈 사실은 다음 조회에서 반영됩니다. 즉시 사용을 멈추려면 앱의 자동 위치를 해제하고 저장하세요.

## 업데이트·제거

### 업데이트

**이 버전에는 자동 업데이트가 없습니다.** 새 릴리스에서 직접 내려받습니다.

- 설치형: 트레이에서 종료 → 새 Setup 실행. 같은 설치 위치와 사용자 설정을 유지합니다.
- 포터블: 트레이에서 종료 → 같은 폴더의 EXE/config 교체. 설정은 별도 폴더에 보관됩니다.
- 설치형/포터블은 같은 Windows 사용자 설정을 공유하므로 동시에 사용하지 마세요.

### 제거

- 설치형: 트레이 종료 후 Windows **설정 → 앱 → 설치된 앱 → ThemeTray → 제거**.
- 포터블: 앱 설정의 로그인 시 실행을 해제하고 저장 → 트레이 종료 → 압축 해제한 폴더 삭제.
- **무인·기업 관리 도구용 제거는 이번 베타의 지원 범위가 아닙니다.** Windows 설정의 대화형 제거를 사용하세요. 제거 프로세스 실행 자체의 종료코드만으로 완료를 판단하지 마세요.
- 설치형 제거는 **해당 설치 경로를 가리키는 자동 실행 항목만** 정리합니다. 다른 경로의 등록은 건드리지 않습니다.
- 설정과 오류 로그는 기본 보존됩니다. 완전히 지우려면 `%LOCALAPPDATA%\ThemeTray`를 사용자가 삭제하세요.
- 제거해도 현재 라이트/다크 상태는 유지됩니다.

## 제한·알려진 사항

- 일부 앱은 자체 테마 설정을 따르거나 다시 열어야 변경됩니다.
- 다른 테마 자동화 프로그램과 함께 쓰면 서로 덮어쓸 수 있습니다.
- 꺼져 있거나 종료된 동안에는 작동하지 않습니다.
- 현재는 코드 서명·자동 업데이트·Microsoft Store 등록이 없습니다.
- Windows 작업 관리자에서 시작 앱을 별도로 비활성화했다면 그 설정도 확인하세요.
- 사용 환경과 UI 사용 이력에 따라 메모리가 달라집니다. 고정 메모리 상한이나 항상 0% CPU를 보장하지 않습니다.
